# Job Description — KHABEER Group for Software Industries

**Job Title:** Mid-Level Full Stack .NET Developer
**Company:** KHABEER Group for Software Industries
**Location:** 5th Settlement, Cairo, Egypt
**Employment Type:** Full-time
**Apply:** hr@khabeergroup.com

## About the Role
Backend development using .NET technologies, contributing to scalable backend systems and enterprise web/mobile applications.

## Key Responsibilities
- Design, develop, and maintain backend systems for mobile and web applications using .NET technologies.
- Develop and support websites, including custom plugin development and modifications to existing plugins.
- Build complete web portals with database backends based on business requirements.
- Write clean, reusable, well-structured code following industry best practices.
- Participate in software architecture discussions, code reviews, and technical planning.
- Design and implement unit tests; maintain legacy systems when needed.
- Optimize applications for speed, scalability, and performance.
- Collaborate with cross-functional teams.
- Research and adopt new technologies.

## Job Requirements
- Bachelor's degree in Computer Science or related field.
- 1–3 years of hands-on experience in C# / .NET Framework (4.x).
- Strong knowledge of C#, OOP, and Design Patterns.
- Proficiency in JavaScript, jQuery, HTML, and CSS.
- Solid experience with WCF, Web API, REST, and SOAP services.
- Experience with DevExpress components.
- Good experience with SQL Server or Oracle databases.
- Familiarity with Git, TFS, and Azure DevOps.
- Understanding of Agile/Scrum methodologies.
